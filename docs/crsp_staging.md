# CRSP CIZ source staging

`stage-crsp` converts the received WRDS daily and historical Names CSVs to private
Parquet files and DuckDB tables. Source bytes are hashed and never changed. It
does not create CIK links or an `import-market` manifest; the receipt explicitly
records that source release, terminal coverage, historical identities and
point-in-time availability still need review.

```bash
uv run disclosure stage-crsp \
  --daily data/raw/wrds/2026-10-10/crsp_daily_pilot.csv \
  --names data/raw/wrds/2026-10-09/crsp_names_pilot.csv \
  --request-start 2014-11-04 --request-end 2021-12-28 \
  --output data/staging/crsp-pilot-v1
```

Use a new output directory for another run. Existing output is preserved.
Request dates are caller declarations, not proof of the submitted WRDS query.

| Output | Source conversion |
|---|---|
| `daily_returns.parquet` | PERMNO, date, DlyRet unchanged, explicit Y/N terminal flag and original missing code |
| `market_returns.parquet` | One `vwretd` per date; conflicting values across securities are rejected |
| `security_snapshots.parquet` | DlyCap times 1,000 USD; exact-date historical SIC and matched Names interval |
| `staging.duckdb` | Queryable copies of these three tables |
| `staging_receipt.json` | Raw/table/code hashes, requested coverage and unresolved research gates |

The documented conversion uses DlyRet as delivered and never adds a separate
legacy DLRET. Literal `NA` in DlyRetMissFlg is preserved as an available-return code;
other codes currently stop staging for dictionary review rather than being filled
or silently dropped. Dates are checked before return values are interpreted, and
requests beyond the development label horizon are refused.

Missing or zero capitalization is retained and flagged invalid for controls. It
does not become a valid size observation. Negative or nonfinite capitalization
is rejected. Industry comes from `siccd` in one inclusive dated Names interval,
never from header SIC. Interval overlaps, missing date matches and PERMCO
disagreements are rejected. Dated coverage does not certify contemporaneous data
vintages; that gate remains false.

Coverage reports compare the requested exchange sessions with delivered rows,
ending stock coverage at an observed terminal flag if one exists. With no terminal
flag, the whole requested window remains unaccounted for after the last row. This
does not imply that post-delisting trading rows should exist; it exposes that a
terminal event has not been established from the supplied file. No payoff, return,
benchmark observation or continuation row is manufactured.

## Current actual exports

The 36,000-row pilot stages successfully: 20 securities, 1,800 benchmark sessions,
36,000 dated snapshots and no missing requested sessions. Its source coverage is
complete for the existing pilot request, but it is not model-ready.

The separate WFM file has ten ordinary rows through 25 August 2017 and no Y flag.
Its ten benchmark observations match the main pilot, and the ordinary price-change
arithmetic agrees within the CSV's six-decimal return rounding. The final cash
payoff is absent, so terminal handling has **not** passed an actual-source test.
The [delisting evidence note](wrds_delisting_check.md) records the diagnostic next
step. No event labels, controls or fitted models were generated by staging.

Tests use invented source records to check units, industry changes, missing flags,
holdout refusal, duplicate/ambiguous data, terminal cash arithmetic and preservation
of prior output. They are engineering checks, not independent human sign-off.
